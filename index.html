02 · Question interface

EFMW Tutor

A local /api/tutor endpoint accepts prompts and returns model diagnostics. Generated text requires a separately configured language backend.

What happens to a prompt

The engine makes its update steps explicit so they can be inspected and tested.

InputTokenize the prompt and create a stable hashed feature sketch.
UpdateCombine the observation with prior state using bounded feedback and update-rate settings.
MeasureReport state change and a stability score derived from that change.
RespondOptionally use a separately configured language model; otherwise return diagnostics only.

Run it locally

The Python server binds to localhost. Start without a language model for state diagnostics, or configure a compatible Hugging Face model explicitly for generated text.

Diagnostics only

Start the local page and API without downloading model weights.

python3 "MillieComplex EFMW AGI.py" --serve

With an optional language model

Install the documented dependencies and choose a compatible model ID.

python3 "MillieComplex EFMW AGI.py" --serve --model-name MODEL_ID
Demo and checks: --demo / --self-testNext.js package setup

Interpret the output carefully

The token-hash encoder is a deterministic feature sketch, not a semantic embedding. State stability measures change in this implementation’s internal vector; it does not establish truth, consciousness, intelligence, or a physical law. Text generation is optional and separate from that diagnostic.
